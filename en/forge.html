Forge

Mini compiler toolkit — a general-purpose JavaScript build and obfuscation pipeline. Transform, protect, and optimize your code in seconds.

View on GitHub

What it does

Compiler

Parses JavaScript source code and transforms it through a configurable pipeline. Supports custom AST passes and intermediate representations.

Obfuscator

Protects your code with variable renaming, string encoding, control flow flattening, and dead code injection. Output is hard to reverse-engineer.

Build Pipeline

Chains compilation, transformation, and output generation into a single command. Handles source maps and module resolution automatically.

Usage

# compile a file
forge build src/index.js -o dist/

# obfuscate with protection level
forge protect src/app.js --level high

# full pipeline
forge run src/ --out dist/ --sourcemap --minify
